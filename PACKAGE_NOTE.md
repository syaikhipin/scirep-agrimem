# Package Note

This GitHub supplementary package is built around the released benchmark artifacts rather than the manuscript files.

For experiment provenance:
- the released benchmark code is provided under `scripts/` and `configs/`
- the manuscript tables are aligned to the released result artifacts in:
  - `results/full_benchmark_v2/summary_complete.csv`
  - `results/full_benchmark_v2/benchmark_results_complete.json`

Scope note:
- AgriConvMem and AgriMultiHop are synthetic benchmark datasets
- the reported evaluation is a synthetic-proxy benchmark, not an official LoCoMo or HotpotQA leaderboard evaluation
- the package should therefore be described as a benchmark supplementary archive, not as a standalone reproducibility archive for the full training and generation pipeline
