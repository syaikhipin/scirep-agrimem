# Benchmark Result Files

These are the benchmark result artifacts reported in the accompanying manuscript.

- `summary_complete.csv`
  Main aggregate table across all five systems.
- `benchmark_results_complete.json`
  Full benchmark output with per-question predictions and judge labels.
- `locomo_by_category_complete.csv`
  AgriConvMem category-level F1 breakdown.
- `hotpotqa_by_type_complete.csv`
  AgriMultiHop type-level F1 breakdown.
- `memorygraph_results.json`
  Additional MemoryGraph output artifact retained from the released benchmark package.
